# 🌧️ Smart Rain Prediction System

A modern weather prediction system built using FastAPI and OpenWeather API.

## 🚀 Features

- Live weather monitoring
- Intelligent rain probability prediction
- Humidity analysis
- Pressure analysis
- Cloud coverage tracking
- Wind speed analysis
- Visibility analysis
- Modern dashboard UI

## 🛠️ Tech Stack

- Python
- FastAPI
- HTML
- CSS
- OpenWeather API

## 📂 Project Structure

```bash
Rain_pridiction_system/

├── main.py
├── weather.py
├── prediction.py
├── templates/
├── static/
├── .env
└── README.md
```

## ⚡ Installation

```bash
git clone YOUR_REPO_URL

cd smart-rain-prediction-system

pip install -r requirements.txt

uvicorn main:app --reload
```
